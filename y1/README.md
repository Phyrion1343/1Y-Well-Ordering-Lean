# 1-Y 展开器

交付文件是上一级的 `1-Y展开器.html`，直接用浏览器打开即可；脚本、样式均已内联，不需要联网、安装依赖或启动服务器。两个 Downloads 原文件保持原样。

## 规则与实现

- 每一有限阶差行只沿上一行的父项链选父。无父项的格子不再产生阶差项。
- 提取取各列顶值；提取行的拟父链由下层的左右腿确定，不重用最初的父链。
- 坏根取末列第一次出现父差为 1 的位置。完整图仍展示其他列尚需提取的部分，因此完整图层数可能大于本次展开所需层数。
- 一对左右腿用 `parents[r][c] = p` 表示：同一行子项 `(r,c)` 的父项为 `(r,p)`，两腿在阶差项 `(r+1,c)` 相会。
- 顶点用实际腿路径求得，遍历不低于根列顶行。提取拟父链不能直接代替这里的路径，特别是顶值为 1 的列。
- 轮廓边复制到 `(r+Δ,c+nL) → (r+Δ,p+nL)`；普通平移边的行号不变，父在好部时仍指向原父。`Δ` 每轮由当时末列高度减根列高度取得。
- 参考边在同一横移位置填补提升留下的行。所有边确定后，由上层提取值向下、向右填数，不按新数值重新挑选父项。
- 删除末项保留该位置原有的低行父关系。复制次数 N 沿用附件含义：删末项后追加 N 份坏部，长度为 `原长度−1+N×坏部长度`。N=0 仅删末项。

规则交叉核对来源：[Googology Wiki：Y序列](https://wiki.googology.top/index.php/Y%E5%BA%8F%E5%88%97)。以用户本次给出的规则和复制次数约定为准。

## 界面

保留好部绿色、坏根红色、原坏部黑色、复制块天蓝/金黄交替、父留好部特殊项紫色，以及每层最高行黑色。保留实时展开、标准式判断、点击截取、缩放和单独/合并 JPG 保存。行标为 `R 0`、`R ω`、`R ω+1`、`R ω·2` 等。

旧“无提升”是 0-Y 的实验模式，未将它作为 1-Y 规则继续提供。

数值使用 BigInt。为避免浏览器卡死，设置 3000 列、250000 个行列格、256 层等计算上限；达到上限明确报错，不静默截断。标准式检查达到限制时显示“暂未确定”，不会把超限当作非标准式。

## 开发与验证

- `engine.js`：算法源文件。
- `bundle.cjs`：将算法重新内联到交付 HTML。
- `test.cjs`：有限/提取祖先反例、展开结构与数值不变量、781 个短序列的穷举测试。
- `audit.cjs`：独立的父项重建核对。
- `ui-test.cjs`：本机 Edge 的离线页面、配色、行标、缩放、截取、标准式、JPG 导出、错误状态与手机宽度检查。

```text
node y1/bundle.cjs
node y1/test.cjs
node y1/ui-test.cjs
```

浏览器测试使用当前 Codex 随附 Playwright 的绝对路径；换机器运行测试时需调整该路径及 Edge 路径。交付 HTML 本身无此依赖。
